How to download Xiaohongshu (RedNote) videos and image notes with a Chrome extension

Short answer: a paste-a-link converter can usually hand you one video file, and that is about it — image sets, the cover at full size and the note's text are all lost, and you have just handed your note URL to a stranger's server. A browser extension works on the page you are already looking at, so one click saves the video and the images and a caption .txt into a folder named after the author and the title. Below: what each option really gives you, and the exact steps for the extension route.

The three ways people save a RedNote note

1. Paste-a-link download websites. You copy the note's share link, paste it into a form, wait for it to resolve, download one file. It works for a single video, and it breaks on everything else: multi-image notes come back as one image or nothing, the caption text is not part of the offer, the file lands in your Downloads folder with a random name, and the request — including the link you pasted — goes to whoever runs that site, which is also where the ads live.

2. Screen recording or the phone's own save button. Fine for one clip you want to keep. You get whatever resolution the app shows, a watermark on some content types, and no text file at all. On desktop Xiaohongshu, the browser's own save options are limited to what the site exposes.

3. A browser extension that reads the page you are on. Because it runs where the note is already rendered, it sees everything the site already loaded for you: the video source, every image in the set, the cover, the title and the body text. No link copying, no third-party server in the loop, and the whole note lands in one folder.

Step by step: pack one note

  1. 1

    Install from the Chrome Web Store

    Search for Social Grabber or use the button above. Nothing to register, no key, no sign-in step.

  2. 2

    Open the note in your browser

    Browse Xiaohongshu normally — xiaohongshu.com/explore/<note-id> or a note you clicked into from the feed. If the note itself needs you logged in to view, be logged in as usual; the extension never asks for platform credentials.

  3. 3

    The card appears on the page

    Bottom-left by default, and you can drag it anywhere — the position is remembered. It shows how many items it detected on this note.

  4. 4

    Click “Pack & download”

    Or press Ctrl+Shift+S. Every detected video, image and the cover are saved, together with a caption .txt. A progress bar shows how far along the pack is.

What you get on disk

By default the files go to:

Downloads/SocialGrabber/Xiaohongshu/<author>/<publish-date>_<title>_<note-id>/

The note id is part of the folder name on purpose: two notes from the same author that happen to share a title would otherwise land in one folder and overwrite each other. If a publish date can't be read, the folder simply starts with the title.

Inside that folder: the media files themselves, and a <title>_caption.txt holding the title, the full body text, the author, the source URL and a list of the media saved with it — so the text never gets separated from the footage it belongs to. That .txt also ends with a short, ready-to-copy prompt you can send to any AI chat alongside the video if you want its structure broken down; the extension itself contains no AI and calls no model.

Both the root folder and the Xiaohongshu subfolder name are editable in the extension popup, so you can point packs at an existing project directory instead.

Several notes at once — and the honest limit

On an author's profile page the card can list the notes your own browsing has already loaded; you tick the ones you want and pack only those. Xiaohongshu's profile feed only delivers thumbnails, so when you pack a ticked list the extension opens and closes those already-loaded cards for you, one after another — the same clicks you would do by hand, with pause and cancel available at any point. What it deliberately does not do: paginate, crawl the account, or fetch notes you never scrolled to. If you want more of an author's notes, scroll the page yourself first.

Frequently asked questions

Do I need to log in to Xiaohongshu to download a note?

The extension never asks for platform credentials and has no account of its own. But if Xiaohongshu itself requires you to be logged in to view a note, you need to be logged in in that browser tab — the extension can only save media the page has already loaded for you.

Does it download the video without a watermark?

It saves the source address the page itself loaded. When a note exposes a clean video URL, that is what gets downloaded; when the only variant the page offers carries the platform watermark, that is what you get. The extension never re-encodes a file and never adds a watermark of its own.

Can I download every note on someone's profile?

Only the notes your own browsing has already loaded. The card lists the notes currently on the profile page, you tick the ones you want, and packing opens those already-loaded cards one at a time. It does not paginate, crawl the account or fetch notes you have not scrolled to.

Where do the files go?

By default into Downloads/SocialGrabber/Xiaohongshu/<author>/<publish-date>_<title>_<note-id>/, with a <title>_caption.txt next to the media. The note id is part of the folder name so two notes with the same title cannot overwrite each other. The root folder and the per-platform subfolder can both be changed in the extension popup.

Is the extension free? Does it upload anything?

It is free, with no sign-up. There is no server behind it: detection, parsing and downloading all happen inside your browser, and no page content is uploaded. The only outbound requests are the plain GETs for the exact files you chose to save.

Can I use this on Douyin or TikTok too?

Yes — the same extension covers Douyin, Xiaohongshu, TikTok, Instagram and Pinterest, with a bilingual interface that follows the page language.
